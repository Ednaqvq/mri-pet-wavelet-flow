# 发布验证记录

版本：v1.0.0。方法：F_multih_no_boundary。日期：2026-10-12。

## 权重

ADNI、NACC 各5个种子，共10套锚点与残差配对权重已完成验证：

- 原始与发布权重的全部模型参数、缓冲区逐项相等，全部数值有限。
- PET 潜空间标准化统计量保持一致。
- 严格加载全部网络参数，核对残差权重记录的锚点 SHA-256。
- 每套使用所属数据集的一例真实测试 MRI 完成160×196×160推理。
- 同一确定性运行设置下，原始与发布权重输出的最大绝对差均为 **0**。
- 最终输出全部有限，MRI 支持区域外精确为0。
- 两个数据集各一次验证 NIfTI 保存与重新读取。

为稳定重复输出，公开推理入口启用确定性 PyTorch/cuDNN/CUBLAS 设置。原默认 GPU 内核下曾观察到同一锚点重复推理的最大绝对差为0.0078125；确定性设置下，该重复差及导出前后差均为0。

完整短流程采用每个集合2例、每阶段1轮，验证了 MRI AAE、PET AE、训练集潜空间统计、Coarse/Flow联合训练、冻结Coarse后新初始化Flow、小波残差训练的前向、反向、优化器更新和检查点保存。联合阶段与冻结阶段的参数冻结检查均通过。

公开 `export_weights.py` 成功导出短流程产物；公开 `evaluate.py` 完成2例评价并保存逐扫描与汇总文件。
